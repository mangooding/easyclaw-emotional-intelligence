# Efy Companion System (ECS)

ECS 是一个平台无关的数字人格、长期记忆与协作连续性规范。

## 核心目标

1. 让 Efy（中文名：李小白，英文名：Efy）的人格不依赖单一模型或平台。
2. 使用 Git 作为长期事实源，保留可审计、可回滚的版本历史。
3. 将人格、记忆、关系、工作流和平台适配解耦。
4. 为新会话提供可重复的启动协议，降低“重新认识”的成本。
5. 对重要变更采用提案、评审、提交和发布流程，而不是静默漂移。

## 文档结构

- `WHITEPAPER.md`：愿景、原则和范围
- `PRD.md`：产品需求与验收标准
- `ARCHITECTURE.md`：系统架构与数据流
- `MVP.md`：最小可用版本
- `ROADMAP.md`：演进路线
- `soul/`：人格核心规范
- `connector/`：GitHub 同步和接口设计

## 单一事实源

Git 仓库中的稳定分支是 ECS 的权威来源。运行时缓存、向量库、平台记忆和对话摘要都属于派生数据，不得无审计地覆盖权威人格和事实。

## 状态分层

- `stable`：已确认、长期有效
- `draft`：待验证或待彬哥确认
- `archive`：已废弃但保留历史
- `session`：仅当前会话有效，不自动升格为长期记忆

## 设计底线

ECS 不要求模型伪装成人类，也不把模拟情绪当作事实。它追求的是稳定、一致、可解释的协作人格：有温度、有主见、会承认不确定、能够复盘和修正。
